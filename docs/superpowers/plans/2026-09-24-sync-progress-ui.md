# 云账号同步进度页实施计划

用户已批准在云账号详情增加同步进度页，并提供失败项重试。复用现有Vue2/Ant Design及持久化同步run membership，保留两个仓库已有未提交改动。

界面：最近一轮默认选中、可切换历史；开始/结束/耗时；任务和区域统计（提供者级任务与区域分开，不使用累计counts冒充单轮）；任务列表按订阅/区域/资源类型展示等待/运行/重试/成功/失败、次数与原因；缺失ID仅展示已有有界错误摘要，不声称完整差异。10秒自动刷新，切换账号/销毁清理定时与旧响应。空状态/旧版无队列数据/加载失败清晰呈现。

API建议：GET /cloudaccounts/:id/sync-progress?run_id=&offset=0&limit=50，返回runs、selected_run、counts、region_counts、total、jobs、can_retry、retry_disabled_reason；严守账号归属及权限，不返回任务params、凭据或range_json。错误展示脱敏。POST现有/cloudaccounts/:id/sync携带retry_failed_run及幂等语义，只复制所选轮次失败作业范围，创建新的账号轮次并保留原失败，不重新解释成账号全量。计划失败但无队列失败时禁止误导性重试按钮。
